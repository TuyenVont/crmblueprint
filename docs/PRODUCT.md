# CRM Product

## Mục tiêu

CRM SaaS giúp doanh nghiệp quản lý quy trình bán hàng:

Lead → Contact/Company → Deal → Pipeline → Won/Lost.

## Người dùng

- Owner
- Admin
- Sales Manager
- Sales
- CSKH

- Đăng nhập
- Workspace
- Users / Teams / Roles

- Companies
- Deals
- Pipeline / Stage động
- Kanban
- Activities / Timeline
- Tasks

- Search / Filter

## Luồng chính

User đăng nhập
→ tạo Lead
→ assign Sales
→ chăm sóc Lead
→ convert thành Contact/Company/Deal
→ Deal vào Pipeline
→ di chuyển qua các Stage
→ thêm Product / Task / Activity
→ Deal Won hoặc Lost
→ Timeline và Report cập nhật.
